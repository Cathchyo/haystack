# 基线输出复盘

## 总体结论

基线输出可读性较好，数字没有明显错误，也能识别主要类型和主要区域；但它还不能完成目标中的“新增扰动分析”和“具体位置、面积相对大小分析”。当前主要瓶颈不是语言表达，而是输入给模型的事实不足。

## 做得较好的部分

- 保持了“数据”和“分析”两个主体部分。
- 图斑数、面积和占比与输入数据一致。
- 正确使用了“候选”“未确认”等限制性措辞。
- 分别分析了采伐、森林火灾和植被胁迫。
- 没有把“未发现记录”写成“不存在扰动”。

## 主要不足

| 问题 | 原因 | 影响 |
|---|---|---|
| 无法分析真正的本期新增 | 输入只有 `slgr_detected_rec` 汇总，没有四分类结果 | 周报只能描述“近期关注清单” |
| 位置过于粗略 | 只有五个大区域的汇总，没有新增图斑坐标或更细区域 | 只能回答大致区域，不能回答具体发生在哪里 |
| 无法判断面积大不大 | 没有单个新增图斑面积及邻近同类面积分布 | 只能报告总面积，不能进行相对面积分析 |
| 没有新增确认数据 | 输入未包含 `slgr_confirm` 的本期分类结果 | 无法展示本期新增算法确认扰动 |
| 重点图斑无法列出 | 没有图斑级事实 | 无法指出最值得关注的具体事件 |
| 出现了额外处置建议 | 提示词没有禁止模型提出建议 | “优先核查”“结合火点数据”等内容超出当前周报核心目标 |
| 无法追溯事实 | 输入没有 `event_id`、数据批次和事实来源标识 | 报告中的事件无法回查到源图斑 |

## 针对性改进顺序

1. 先生成每个图斑的四分类结果，明确真正的本期新增确认和本期新增未确认。
2. 给模型提供新增图斑的区域、中心点和面积。
3. 由程序计算邻近同类斑块的面积中位数和面积分位。
4. 提供重点新增图斑清单，而不是只提供汇总数据。
5. 在提示词中明确禁止额外提出原因、风险等级和处置建议。
6. 最后再判断是否需要扩充知识库；当前问题主要不能靠知识库解决。
