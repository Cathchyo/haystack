# QGIS 扰动图层：参数—含义表

| 参数 | 专业定义（按当前代码核对） | 通俗理解 |
|---|---|---|
| `brightness` | 基于蓝、绿、红、近红外、短波红外 1 和短波红外 2 六个波段的变化残差，经缨帽变换亮度系数线性组合得到的图斑级亮度变化分量；波段变化残差为有效观测值与 SCCD 时序模型预测值之差。 | 这片地的“亮度”比它往常应该有的样子改变了多少；不是整张卫星照片的亮度。 |
| `greenness` | 基于六个波段的变化残差，经缨帽变换绿度系数线性组合得到的图斑级绿度变化分量，用于表征绿色植被光谱特征相对 SCCD 时序模型预测状态的变化。 | 这片地的“绿色植被特征”相对正常情况变化了多少。 |
| `wetness_ch` | 基于六个波段的变化残差，经缨帽变换湿度系数线性组合得到的图斑级湿度变化分量，用于表征植被冠层及地表水分相关光谱特征相对 SCCD 时序模型预测状态的变化方向和幅度。 | 与它平时应有的状态相比，地表表现得更“干”还是更“湿”。 |
| `disturbanc`（界面显示名称可能是 `disturbance`） | SCCD 计算的图斑级归一化多波段变化幅度，由图斑内像元的归一化变化度量 `norm_cm` 聚合后按比例因子 `cm_scale = 100` 缩放得到，用于衡量观测光谱相对时序模型预测值的综合偏离强度。 | 一个综合的“偏离正常状态有多明显”的分数；数值较大通常表示变化较明显。 |
| `detection` | 扰动对象的检测登记日期；对象首次满足对象级扰动检测条件时写入当前处理日期，并在该检测记录持续有效时由后续处理批次沿用。 | 系统最早什么时候把它登记为一个待关注的扰动。 |
| `last_clear` | 扰动对象所关联像元最近一次通过云、阴影等质量控制的有效遥感观测日期，图斑层面以各像元有效观测日期的众数表示。 | 最后一张能看清这片地的卫星影像是哪天拍的。 |
| `disturba_1` | SCCD 估计的扰动发生日期，对应图斑内像元变化日期 `chg_date` 的众数，用于表征该扰动对象最具代表性的变化发生时间。 | 算法估计这块地大约从哪一天开始发生扰动。 |
| `epoch` | 扰动对象写入数据库时对应的增量处理批次序号；确认对象记录为 `conf_epoch`，候选对象记录为 `generation_epoch`，每个批次对应一个连续的遥感数据处理时间窗口。 | 这块图斑是在系统第几批处理新影像时生成或确认的，同一批可以有多个图斑。 |
| `agent` | 扰动驱动类型的分类标签，用于描述引起地表变化的主要事件类型；字段值 `logging` 表示森林采伐扰动。 | “这次变化是类型的扰动”。 |
| `province` | 扰动图斑的区域归属名称，通过图斑空间位置与区域边界数据的空间关联获得；字段值 `daxing` 表示该图斑所属的区域标签。 | 这块地被归在哪个地区。 |
