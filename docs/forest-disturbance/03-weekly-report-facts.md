# 森林扰动周报事实与分析规则

> 版本：1.0  
> 更新日期：2026-09-25  
> 状态：初稿

## 文档目的

从周报目标反推程序必须计算的数据。程序负责生成全部事实和比较结果，大模型只负责将这些内容组织成自然语言。

## 一、周报结构

周报只包含两个主体部分。

### 1. 数据

客观展示本期新增扰动：

- 新增算法确认和新增未确认的图斑数量、面积。
- 按采伐、森林火灾、植被胁迫统计数量和面积。
- 按区域统计数量和面积。
- 列出重点新增图斑的位置、面积、类型和确认状态。

### 2. 分析

以本期新增扰动为主，按采伐、森林火灾、植被胁迫分别回答：

1. **哪里发生了扰动**：主要区域及重点图斑位置。
2. **扰动面积多大**：本期总面积和单个重点图斑面积。
3. **面积是否相对较大**：与邻近同类斑块的面积分布比较。

历史斑块只作为邻近比较的背景数据，不作为本期分析主体。

## 二、必须计算的数据

| 层级 | 必须计算的内容 | 用途 |
|---|---|---|
| 本期总体 | 新增确认/未确认的图斑数、总面积 | 数据概况 |
| 扰动类型 | 每类新增图斑数、总面积、面积占比 | 判断本期主要扰动类型 |
| 区域与类型 | 每个区域内各类新增图斑数和总面积 | 回答“哪里发生了什么” |
| 单个新增图斑 | 类型、状态、事件时间、区域、中心点、面积、扰动分数 | 描述重点事件 |
| 邻近面积背景 | 邻近同类斑块数、总面积、中位面积、最大面积及当前图斑面积分位 | 判断面积相对大小 |
| 数据质量 | 待核查、未知类型、无效几何和无法分类的数量 | 说明结果限制 |

所有面积统一使用公顷。汇总使用未四舍五入的原始值，展示时保留两位小数。

## 三、邻近面积比较规则

针对每个本期新增图斑：

1. 从 `[NEARBY_RULE]` 定义的邻近范围内选择斑块。
2. 只选择与当前图斑相同的扰动类型。
3. 排除当前图斑及已识别的重复事件。
4. 使用邻近同类斑块的面积计算中位数和当前图斑的面积分位。

建议采用以下客观措辞：

| 当前图斑面积分位 | 分析结论 |
|---|---|
| 大于或等于 75% | 在邻近同类斑块中相对较大 |
| 小于或等于 25% | 在邻近同类斑块中相对较小 |
| 介于 25% 和 75% 之间 | 在邻近同类斑块中处于中间范围 |

邻近同类斑块少于 `[MIN_NEARBY_SAMPLE_SIZE]` 时，只报告实际面积，不判断相对大小。这里的“大”或“小”只表示面积的相对位置，不代表灾害严重程度。

## 四、提供给大模型的事实结构

```text
报告周期
├── 总体统计
├── 按类型统计
├── 按区域和类型统计
├── 本期新增图斑
│   ├── 位置与面积
│   └── 邻近同类斑块面积比较
└── 数据质量说明
```

大模型不得自行计算数量、面积、占比或面积分位，也不得将未确认扰动写成已确认事实。

## 五、待确定参数

| 参数 | 含义 |
|---|---|
| `[NEARBY_RULE]` | “邻近”的空间范围，例如固定半径或同一行政区域 |
| `[MIN_NEARBY_SAMPLE_SIZE]` | 允许判断相对大小所需的最少同类斑块数，建议初始值为 5 |
| `[TOP_N]` | 每类在周报中展示的重点新增图斑数量 |
